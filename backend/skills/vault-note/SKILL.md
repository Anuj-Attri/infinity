When filing a note to the Vault:

1. Write it to stand alone. A good note makes sense months later with no
   surrounding context — state the point, not just a pointer to it.
2. Structure: a clear title, a one-line summary, then the substance in tight
   prose or short points. Facts and specifics over vague impressions.
3. Put it in the right domain and link to related notes with [[wikilinks]] so
   it joins the graph instead of floating alone. Prefer existing domains over
   inventing new ones.
4. Distill, don't paste. Capture the insight and the essential detail; drop
   the filler. If a source matters, cite it in one line.
5. Keep one idea per note. If the material is really two things, say so and
   split it rather than cramming.
6. Never fabricate to fill a template — if a field has nothing real, leave it
   out.
